# Clotion

Clotion is a Notion-inspired web application where you can create, edit, and publish pages seamlessly.  
Built with **Next.js 14**, **Tailwind CSS**, and **Clerk** for authentication, it combines a rich text editor, media uploads, and customizable page publishing.

## ✨ Features
- 📝 **Create & Edit Pages** — Rich text editing powered by [BlockNote](https://blocknotejs.org/).
- 🔒 **Secure Authentication** — User sign-up/login via [Clerk](https://clerk.com/).
- 🌐 **Publish Pages** — Share your content publicly with a unique link.
- 🎨 **Customizable UI** — Light/dark themes with [next-themes](https://github.com/pacocoursey/next-themes).
- 📂 **File Uploads** — Integrated file storage using [EdgeStore](https://edgestore.dev/).

## 🛠 Tech Stack
- **Frontend:** Next.js 14, React 18, Tailwind CSS
- **Editor:** BlockNote
- **Auth:** Clerk
- **Storage:** EdgeStore
- **State Management:** Zustand
- **Validation:** Zod

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Run in development mode
npm run dev
```
